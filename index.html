Understanding tokens

The basics — no prior experience needed

AI models don't read text the way you do. Before a prompt reaches the model, it's chopped into small pieces called tokens. Models read and bill by the token, so understanding them is the first step to predicting and controlling your API costs.

What is a token?

A token is a chunk of text — a short word like cat, part of a longer word (token + ization), a piece of punctuation, or a single character. Each model has its own fixed vocabulary of roughly 100,000–200,000 tokens, so the same text can split differently between providers.

Why tokens matter

Providers charge per token, priced per million and split into two rates: input (what you send) and output (what the model writes back). Output is usually 3–5× more expensive than input. Your bill is based on token count — not word count.

Input vs. output

Input tokens are everything you send: your instructions, pasted text or code, and earlier conversation. Output tokens are what the model generates. Total cost = input tokens × input price + output tokens × output price.

Context window

Every model has a maximum amount of text it can consider at once — input and output combined. This is the context window. Exceed it and older content gets dropped, or the request is rejected.

Rules of thumb

  • 1 token ≈ 4 characters of English
  • 1 token ≈ ¾ of a word
  • 100 tokens ≈ 75 words
  • A short paragraph ≈ 100–150 tokens
  • Code, symbols, and non-English text use more tokens per word

How to spend less

  • Send only the context the model actually needs
  • Summarize long chats instead of resending every message
  • Use a smaller, cheaper model for simple tasks
  • Set a max output length so replies can't run away
  • Batch related questions into a single request
